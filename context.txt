

**PROJET**
WadiGuard est un système marocain d'alerte précoce aux crues. Des capteurs IoT placés en amont sur un wadi (oued) détectent la montée des eaux, le système prédit la zone affectée, génère des alertes multi-canaux (SMS, WhatsApp, sirènes, panneaux LED), et bloque automatiquement les routes dangereuses — le tout sans intervention humaine. Ce dashboard est l'interface centrale pour les autorités (Protection Civile, DGM, municipalité).

---

**STACK IMPOSÉE**
React + Tailwind CSS + Recharts (graphiques) + Leaflet (carte) + Lucide React (icônes). Tout en un seul fichier JSX. Aucun backend — toutes les données sont simulées/hardcodées avec des timers JavaScript.

**COMPOSANT 3 — CARTE LEAFLET (centre)**

Centre de la carte : `35.7595° N, -5.8340° W` (Tanger, Maroc), zoom 11.

Éléments sur la carte :
1. **Ligne bleue** le long du wadi (Oued Mghogha ou similaire) — polyline bleue épaisse avec légère transparence
2. **3 markers capteurs** custom (icône radar SVG inline, couleur selon statut) aux coordonnées :
   - UAP-01 : `35.680, -5.720` (25km amont)
   - UAP-02 : `35.700, -5.760` (15km amont)
   - DNP-01 : `35.740, -5.800` (pont)
3. **2 icônes panneaux LED** (rectangle rouge/vert selon alerte) sur la route principale
4. **Polygon semi-transparent rouge** sur la zone ville basse de Tanger qui apparaît en alerte ROUGE (zone d'impact prédite)
5. **Popup au clic** sur chaque marker : nom, valeur actuelle, statut

Tile layer : `CartoDB Dark Matter` (tiles sombres, parfait pour le thème) → URL : `https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png`

**COMPOSANT 4 — RIGHT PANEL**

**Alert Level Badge** (en haut, grand) :
- Un grand badge centré : `NIVEAU VERT / ORANGE / ROUGE`
- Texte associé : `Situation normale` / `Surveillance renforcée` / `ALERTE MAXIMALE`
- En rouge : animation `animate-pulse` sur tout le badge + border rouge clignotante

**Water Level Gauge** (jauge circulaire ou arc) :
- Valeur en % (0–100%), grande, police monospace
- Arc coloré : vert < 50%, orange 50–75%, rouge > 75%
- Label sous la jauge : `Niveau pont DNP-01`

**Rainfall Meter** :
- Barre verticale ou horizontale animée
- Valeur en mm/h : `12 mm/h` → monte pendant scénario
- Label : `Précipitations amont`

**Notification Feed** (scrollable, en bas du right panel) :
- Liste de logs horodatés qui se remplissent pendant le scénario
- Style terminal/log : fond `#060E1A`, texte monospace
- Chaque ligne : `[14:32:07] 🟠 UAP-01 · Niveau anormal détecté`
- Couleur selon sévérité : vert, orange, rouge

**ANIMATIONS CLÉS**
- Dots de statut : `animate-pulse` CSS quand ROUGE
- Badge alerte ROUGE : bordure clignotante + background pulse
- Polygon carte : `opacity` qui monte de 0 à 0.4 en 1s (transition CSS)
- Notification feed : chaque nouvelle ligne slide-in depuis le bas
- Gauge arc : transition fluide sur la valeur (CSS transition 0.5s)
- Markers carte : scale-up + glow rouge en alerte critique
