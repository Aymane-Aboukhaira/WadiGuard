# Platform Overview

## 1. Core Purpose
The WadiGuard platform is engineered as a real-time Network Operations Center (NOC) dashboard dedicated to hydrological infrastructure monitoring and crisis management. It provides command-level visibility into critical assets (dams, rivers, road networks) by aggregating telemetry data into a highly precise, tactical operational picture. It is designed to act as the primary decision-support interface during escalating weather events.

## 2. Business Value & User Flows
Operational environments demand absolute clarity. The business value of WadiGuard lies in its **unified, high-contrast, zero-shift operational interface**. During data spikes or rapidly evolving crises, operators cannot afford cognitive load from cluttered interfaces or shifting UI layouts.

**Primary User Flows:**
*   **Macro-Surveillance:** Operators monitor the regional map and aggregated status indicators for an immediate understanding of system health.
*   **Targeted Assessment:** Upon alert escalation, operators select specific regions or critical assets. The interface instantly pivots, locking telemetry and impact models onto the isolated target without context switching.
*   **Simulation & Protocol:** Operators run automated scenarios to predict outcomes, reviewing dynamic playbook protocols corresponding to the current threat phase.

## 3. Main Features
*   **Real-Time Simulation Telemetry:** A continuous, high-frequency data engine simulating fluctuating water levels, rainfall, battery life, and latency, mirroring live NOC sensor streams.
*   **Tactical Map Overlays:** Geographic visualization using high-contrast dark tiles, animated river data flows, and active polygon impact zones. Assets are represented by pulsating HTML markers colored by live risk metrics.
*   **Instant Impact Analysis:** Dynamic calculation of exposed populations, severed transit routes, and required response teams based on the selected asset and the severity of the simulated crisis phase.
